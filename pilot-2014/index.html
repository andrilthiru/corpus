Pilot corpus, 2014 — annotated sample
About this sample. The data — sample text, 18-category grammatical tag scheme and the tagged word list — is from a 2014 corpus pilot by Dr K Thirumaran, shown as in the original files apart from a few corrections, tag changes and some words tagged in 2026, all listed under Plan & source. The pilot planned a simple word / grammatical label / root viewer; this interactive version of that viewer was built in October 2026 so the 2014 data can be explored. It is a general Singapore Tamil corpus with grammatical annotation, not a learner error corpus.

Code reference — what each short code means

Every short code used in the word list, with its full Tamil name, English name and examples from the text. Codes are built from parts of the full name, for example பெ = பெயர், வி = வினை, எ / எச் = எச்சம், மு = முற்று, கு = குறிப்பு, எதி.ம = எதிர்மறை, அ = அடை, தொ = தொழில், பதி = பதிலிடு, இ.சொல் = இடைச்சொல்.
