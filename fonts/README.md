# Tamil display font

The app shows Tamil text in **InaiMathi** when that font is installed on the viewer's computer
(it ships with macOS; Windows users need the Anjal InaiMathi build installed).

To make every viewer see the same font, place a web-font file here named exactly:

    fonts/CorpusTamil.woff2

Only add a font whose licence allows web embedding / redistribution. If the file is absent,
the app falls back to Noto Sans Tamil / Latha automatically.
